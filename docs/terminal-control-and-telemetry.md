# 终端板本地控制与遥测 v2

更新日期：2026-10-10。此文档描述已写入代码的软件行为，不代表完成烧录、实物测量或无线链路验证。

## 当前阶段

完成终端本地控制这一纵向切片：环境数据快照 → AUTO/MANUAL/SAFE 策略 → 继电器、风扇、蜂鸣器 → OLED 和遥测。未实现远程 COMMAND/ACK、网关联网、巴法云、米家、Flash 配置保存或看门狗。

所有业务代码放在 User，CubeMX 的 `.ioc`、Core、Drivers 和生成 CMake 文件不修改。当前使用 CMake 构建；未建立本轮改动的 Keil 工程验证结果。

## 上电与输出

- 默认 MANUAL，水泵继电器关闭、风扇 0 档、蜂鸣器关闭。
- RF-300CA 电机沿用用户要求的 0%、30%、50%、80%、100% 档位，20kHz；这不是电机转速标定或厂家认证工况。
- PC14 驱动继电器，PB8/TIM4_CH3 驱动电机，PB9/TIM4_CH4 驱动有源蜂鸣器。
- 停止通过单通道比较值归零，不改变共享定时器的周期。输出状态表示驱动指令，没有出水/转速反馈。
- PB15 为告警指示（低电平亮），PC13 为运行心跳。

## 默认策略（仅软件示例参数）

| 项目 | 参数/行为 |
| --- | --- |
| 通风温度阈值 | 30℃ 启动 2 档，28℃ 恢复关闭；中间区间保持请求 |
| CO2 阈值 | 1200ppm 启动 3 档，1000ppm 恢复关闭 |
| 两种通风请求 | 取较高档；失效的传感器不再参与对应策略 |
| 自动灌溉 | **默认禁用**，需探头校准后通过配置接口启用 |
| 灌溉示例等级 | 干等级 1 开启、湿等级 3 关闭；不是湿度百分比 |
| 单次灌溉 | 最大 10 秒，达到上限停止并锁存 SAFE |
| 停机冷却 | 60 秒，手动也不能绕过，模式切换不清除冷却 |
| 手动风扇 | 60 秒租约，重复同档指令不续期 |
| 数据有效期 | ADC 3.2 秒，DHT22 6 秒，CO2 3 秒 |
| 启动宽限 | 8 秒后开始提示缺失传感器；宽限内也不以无效数据驱动泵 |

无效/过期土壤数据会关泵。ADC 接近电源轨标记为可疑信号，不等于具备完整探头断线诊断。没有液位、流量或电流采集，所以泵运行上限不是硬件缺水/堵转检测。

SAFE 由紧急停止、泵超时、驱动失败或无效配置触发，不自行恢复。明确模式切换可以确认解锁，但驱动未就绪时拒绝解锁。恢复不绕过泵冷却。参数修改也先停止并进入 SAFE。

告警静音只关闭提示声，不清告警和安全限制；出现新告警位时重新提示。

## 按键和页面

每 10ms 采样，20ms 消抖，1500ms 长按；ISR 只发通知，主循环识别事件。长按释放后不再触发短按。

| 操作 | 行为 |
| --- | --- |
| SW1 短按 | 环境 → 风扇 → 灌溉 → 通信 → 故障，循环切页 |
| SW1 长按 | MANUAL → AUTO；AUTO/SAFE → MANUAL。SAFE 解锁仍受就绪检查 |
| SW2 短按（风扇页） | MANUAL 下循环 0～4 档，其他模式拒绝 |
| SW2 短按（灌溉页） | MANUAL 下切换泵输出，仍检查土壤数据和冷却 |
| SW2 短按（其他页） | 切换告警静音 |
| SW2 长按 | 泵/风扇停止并进入 SAFE，自动切到故障页 |

同轮两键长按以 SW2 紧急停止优先，不会被 SW1 解锁。OLED 每行最多 16 个 ASCII 字符，每次仅刷新变化行。

通信页的 Done 是芯片 TX_DONE 次数，不能解释为网关确认次数。RADIO:IDLE 仅表示芯片初始化通过、当前未发送，不能解释为无线链路已经建立。

## 模块和接口

- `control_policy.c/.h`：纯 C 状态机、阈值滞回、租约、泵保护。
- `actuator_service.c/.h`：初始化/应用输出、共享 TIM4 两通道隔离、就绪位。
- `control_service.c/.h`：快照转输入、应用策略、模式和手动命令接口。
- `button_state.c/.h`：纯 C 消抖、长短按；`button_service` 负责读取 GPIO。
- `terminal_view`：纯 C 行格式化；`terminal_ui`：页面、按键命令、局部刷新。
- `co2_parser`：0x2C/6 字节滑动帧校验；`CO2`：64 字节有界接收环、超时重启接收。
- `terminal_telemetry`：定长小端编码与 CRC16；`lora_service`：前台发送状态机。

控制接口返回 `ControlResult_t`：0 成功、1 参数无效、2 模式拒绝、3 传感器无效、4 冷却中、5 驱动或配置未就绪。

主要业务接口：

```c
Control_SetMode(CONTROL_MODE_AUTO, HAL_GetTick());
Control_SetFan(4U, HAL_GetTick());        // 只有 MANUAL 模式允许
Control_SetPump(1U, HAL_GetTick());       // 需要有效土壤数据且已结束冷却
Control_EmergencyStop(HAL_GetTick());
Control_GetSnapshot(&snapshot);
```

纯策略与控制服务须在主循环调用，不从 ISR 直接操作执行器。主循环没有等待 CO2 或 TX_DONE 的长循环，但 DHT22、I2C、SPI/BUSY 仍有有界同步操作，**不是硬实时系统**。旧阻塞接口仅保留供示例兼容，不再被主业务调用。

LoRa 初始化仍有有界延时，只在执行器全部关闭、按键释放时尝试；不在运行泵或风扇时进行长初始化。该限制不替代看门狗或硬件关断保护。

## 遥测 v2：34 字节

**版本 2 不兼容旧 20 字节帧，网关需要按新格式解析。** 当前只有上报，没有远程命令、接收 ACK 或重复命令去重。

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 1 | 0xA5 帧头 |
| 1 | 1 | 版本 2 |
| 2 | 2 | 节点地址（当前 1） |
| 4 | 1 | 类型 1：遥测 |
| 5 | 2 | 发送序号 |
| 7 | 1 | 负载长度 24 |
| 8 | 2 | 有符号温度 ×10 |
| 10 | 2 | 湿度 ×10 |
| 12 | 2 | CO2 ppm |
| 14 | 2 | 光照估算值 |
| 16 | 1 | 土壤估算等级 |
| 17 | 1 | 有效位：bit0 光照，bit1 土壤，bit2 温湿度，bit3 CO2 |
| 18 | 1 | 模式：0 MANUAL，1 AUTO，2 SAFE |
| 19 | 1 | 继电器输出指令 |
| 20 | 1 | 风扇档位 |
| 21 | 1 | 蜂鸣器当前输出指令 |
| 22 | 2 | 风扇占空比千分比 |
| 24 | 2 | 告警位图 |
| 26 | 1 | 就绪位：bit0 电机，bit1 蜂鸣器，bit2 继电器 |
| 27 | 1 | 标志：bit0 静音，bit1 自动灌溉已启用 |
| 28 | 4 | 当前毫秒时基/1000；毫秒时基回绕后也会回绕，不是绝对时间 |
| 32 | 2 | CRC16/Modbus，前 32 字节计算，低字节在前 |

所有多字节字段小端。无效或过期数据的负载写零，同时清有效位，接收方必须先检查有效位，不能把零当成有效环境读数。CRC 只检错，不提供身份认证。

告警位图：0x0001 温度超限，0x0002 CO2 超限，0x0004 土壤无效，0x0008 DHT22 无效，0x0010 CO2 无效，0x0020 泵超时，0x0040 紧急停止，0x0080 执行器未就绪，0x0100 配置无效。
