# RF-300CA-11400 电机驱动修订

## 已确认的依据与边界

- 用户确认实物对应 `1112014.pdf` 中的 RF-300CA-11400-6.0C。
- PDF 第 2 页：额定电压 3V，规定的直流使用范围 1.5～4V。
- PDF 第 3 页：额定电压下空载电流最大 25mA、额定负载电流最大 100mA、指定条件下起动电流最大 330mA。
- 当前板上 CN1 正端接 VCC5V，PB8/TIM4_CH3 控制低边 MOSFET；CH4 为蜂鸣器。
- 本次按上一轮审查结论及用户“直接修改电机代码”的确认实施。
- 用户随后明确确认实际电机在 5V 可正常运行、6V 仅短时运行，并要求开放 100% 软件占空比。
- 按用户确认的工况保留 20kHz，将 0～4 档设为 0%、30%、50%、80%、100%，千分比范围为 0～1000。
- 这不修改 PDF 的原始参数，不构成厂家认可 5V/6V 使用条件或已完成实物验证的结论。
- 不修改 `.ioc`、CubeMX 生成代码或 TIM4 的全局周期；不烧录、不进行硬件测试。

## 接口与行为

1. 初始化必须先清零有效 CCR3，再启动 CH3；重复初始化只停止输出，不重复启动 HAL 通道。
2. 停止只清零 CH3。临时关闭 CH3 比较预装载后写零并恢复原配置，避免等待影子寄存器更新；不发全局更新事件。
3. 初始化和设置接口返回就绪、参数或 PWM 错误，应用启动失败时记录日志并继续传感器服务，不自动运行电机。
4. 未初始化时拒绝控制请求，不更新输出状态，也不保存稍后自动执行的非零请求。
5. 无效档位或超过 1000 千分比上限的占空比均拒绝，保持既有指令；调用方根据返回值决定是否进入安全模式。
6. 零占空比归零档；与预设值匹配时报告对应档位，其余合法值报告自定义档位。
7. 就绪和占空比状态只代表软件驱动状态及已接受指令，不代表电机实际转速、温升或电流。

## 实施与软件验证

- 修订 `motor_control.c/.h`，更新 `app_main.c` 的初始化错误处理。
- 使用主机端 HAL 模拟检查初始化顺序、失败重试、重复初始化、有效范围、拒绝异常输入和 CH4 隔离。
- 构建 CMake Debug/Release 并检查差异；不作电机实测结论。
- 保留供电和续流保护待评估事项，软件不能消除现有 5V 供电与电机规格的差异。

## 满占空比边界验证

- ARR=3599 时：30%/50%/80%/100% 分别对应 CCR3=1080/1800/2880/3600。
- 单独检查 800 和 1000 指令，以及 100% 档在完整计数周期内的 PWM1 比较条件。
- 遍历全部 1001 个合法千分比指令；拒绝 1001、2000 和 65535 等超范围输入。
- 上电、重复初始化和停止仍归零，不因放开上限而自动输出非零占空比。
